# Today I Learned

A learning journal, one lesson at a time. Built with Jekyll.

## Local Development

To run this site locally, you'll need to have [Ruby](https://www.ruby-lang.org/en/documentation/installation/) and [Jekyll](https://jekyllrb.com/docs/installation/) installed.

1. Clone the repository.
2. Run `bundle install` to install dependencies.
3. Run `bundle exec jekyll serve` to build and serve the site locally.
4. Navigate to `http://localhost:4000/today-i-learned/` in your browser.
